# 📚 Шаблон для лабораторных работ

Универсальный шаблон для выполнения лабораторных работ по программированию на C++23 с автоматической генерацией отчетов и поддержкой решения математических задач через Jupyter.

## 🚀 Быстрый старт

### Требования

Для работы с шаблоном необходим **OpenCode** — AI-ассистент для автоматизации разработки.

Всё остальное настроит агент автоматически через команду:

```bash
/install
```

### Выполнение лабораторной работы

```bash
@report path/to/methodology.pdf
```

Агент автоматически:
1. Проверит методичку
2. Реализует решение
3. Решит математические задачи (если требуется)
4. Протестирует код
5. Сгенерирует отчет в PDF

## 📁 Структура проекта

```
lab_template/
├── src/          # Исходный код приложения
├── docs/         # Отчёты в формате Typst
├── images/       # Скриншоты и изображения для отчета
├── build/        # Скомпилированные файлы
└── Makefile      # Автоматизация сборки
```

## 🛠️ Команды сборки

| Команда | Описание |
|---------|----------|
| `make` или `make all` | Полная сборка проекта |
| `make run` | Запуск приложения |
| `make docs` | Сборка документации в PDF |
| `make clean` | Очистка артефактов сборки |

## 🤖 OpenCode Агенты

### Report Agent — оркестратор лабораторных работ

Специализированный AI-агент для **автоматического выполнения лабораторных работ**.

#### ✨ Возможности

- 📖 Анализ методических указаний и извлечение требований
- ✅ Проверка наличия всех необходимых данных (вариант, исходные данные)
- 💻 Реализация решения на C++23 (через агента @coder)
- 📐 Решение математических задач (через агента @math, опционально)
- 🧪 Создание и выполнение тестов (через агента @qa)
- 📄 Генерация отчета в Typst (через агента @writer)
- 🔨 Автоматическая компиляция в PDF

#### 🚀 Как использовать

**Способ 1: Команда**
```bash
@report path/to/methodology.pdf
```

**Способ 2: Интерактивное меню**
1. Несколько раз нажмите `Tab`
2. Выберите агента **report** из списка
3. Укажите путь к методическим указаниям

#### 📋 Рабочий процесс

1. **Верификация** — проверяет методичку и запрашивает недостающие данные
2. **Кодирование** — пишет решение согласно требованиям задачи
3. **Математика** (опционально) — решает математические части через Jupyter
4. **Тестирование** — создает контрольные примеры и проверяет работу
5. **Документирование** — формирует полный отчет с кодом и скриншотами
6. **Компиляция** — собирает финальный PDF-документ

### Math Agent — решение математических задач

Специализированный агент для решения математических задач через JupyterLab.

#### ✨ Возможности

- 📊 Численные методы (интерполяция, аппроксимация, интегрирование, решение уравнений)
- 📈 Линейная алгебра (матрицы, системы уравнений, собственные значения)
- 🔢 Дифференциальные уравнения, статистика и анализ данных
- 📝 Пошаговое описание вычислений с LaTeX-формулами
- 📊 Графики и визуализация результатов
- 📋 Таблицы результатов для отчета

#### 🚀 Как использовать

**Способ 1: Через report** (автоматически)
```bash
@report path/to/methodology.pdf
```

Report определит, нужна ли математика, и вызовет @math при необходимости.

**Способ 2: Прямой вызов**
```bash
@math
```

Укажите задачу или путь к `TASK.md` с описанием вычислений.

## 📚 Структура файлов

Во время выполнения создаются:

```
lab_template/
├── TASK.md              # Описание задания (создаёт @verificator)
├── TEST_SUMMARY.md      # Итоги тестирования (создаёт @qa)
├── src/                 # Исходный код (создаёт @coder)
├── images/              # Скриншоты, графики (создают @coder, @math, @qa)
├── docs/
│   └── index.typ        # Финальный отчет (создаёт @writer)
└── build/
    └── report.pdf       # Скомпилированный отчет (Typst)
```
