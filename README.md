# 📚 Шаблон для лабораторных работ

Универсальный шаблон для выполнения лабораторных работ по программированию на C++23 с автоматической генерацией отчетов.

## 📁 Структура проекта

```
lab_template/
├── src/          # Исходный код приложения
├── docs/         # Отчёты в формате Typst
├── images/       # Скриншоты и изображения для отчета
├── build/        # Скомпилированные файлы
└── Makefile      # Автоматизация сборки
```

## 🛠️ Команды сборки

| Команда | Описание |
|---------|----------|
| `make` или `make all` | Полная сборка проекта |
| `make run` | Запуск приложения |
| `make docs` | Сборка документации в PDF |
| `make clean` | Очистка артефактов сборки |

## 🤖 OpenCode Report Agent

Специализированный AI-агент для **автоматического выполнения лабораторных работ**.

### ✨ Возможности

- 📖 Анализ методических указаний и извлечение требований
- ✅ Проверка наличия всех необходимых данных (вариант, исходные данные)
- 💻 Реализация решения на C++23
- 🧪 Создание и выполнение тестов
- 📄 Генерация отчета в Typst
- 🔨 Автоматическая компиляция в PDF

### 🚀 Как использовать

**Способ 1: Команда**
```bash
@report path/to/methodology.pdf
```

**Способ 2: Интерактивное меню**
1. Несколько раз нажмите `Tab`
2. Выберите агента **report** из списка
3. Укажите путь к методическим указаниям

### 📋 Что делает агент

1. **Верификация** — проверяет методичку и запрашивает недостающие данные
2. **Кодирование** — пишет решение согласно требованиям задачи
3. **Тестирование** — создает контрольные примеры и проверяет работу
4. **Документирование** — формирует полный отчет с кодом и скриншотами
5. **Компиляция** — собирает финальный PDF-документ
